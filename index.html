      How it works
      
          
        
            
      1. GenerateA random 256-bit data key is created in an isolated worker, from the OS's secure random generator.
        2. 
            
      2. EncryptYour data, file name and type are padded and sealed with AES-256-GCM. The header is authenticated too.
        3. 
            
      3. SlotEach unlock method wraps the data key in its own key slot: Shamir shards, Argon2id passphrase, both together, or a hardware passkey.
        4. 
            
      4. ForgetKeys are wiped. Only a slot's key material, held by you, can bring them back.
        5. 
          
      
          
      No public-key cryptography is used, so a future quantum computer has nothing to attack beyond brute force against AES-256. File format, threat model and limits are in the repository's README and SECURITY.md.
