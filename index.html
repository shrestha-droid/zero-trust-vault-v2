Who can open it?

Split the key between people or places, use a passphrase, or both.

Use 4+ random words or a generated passphrase.

Hardened with Argon2id (64 MiB, 3 passes). There is no reset. A forgotten passphrase cannot be recovered.

3

Where should the encrypted file live?

Only ciphertext is ever written. Keys stay with you.

Summary

  • AES-256-GCM authenticated encryption
  • Shamir sharing via an independently audited library
  • Header is tamper-evident (bound as AAD)
  • Size hidden with Padmé padding

Nothing leaves this tab until you seal, and then only ciphertext does.

      How it works
      
          
        
            
      1. GenerateA random 256-bit key is created in this tab from the OS's secure random generator.
        2. 
            
      2. EncryptYour data, file name and type are padded and sealed with AES-256-GCM. The header is authenticated too.
        3. 
            
      3. SplitThe key is cut into N Shamir shards. Any K rebuild it, and fewer reveal nothing at all.
        4. 
            
      4. ForgetThe key is wiped. Only shards (and an optional Argon2id-wrapped copy) can bring it back.
        5. 
          
      
          
      Open source and verifiable. File format, threat model and limits are in the repository's README and SECURITY.md.
